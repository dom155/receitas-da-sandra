# 🍳 Receitas da Sandra

Aplicação web desenvolvida como projeto acadêmico para cadastro, consulta e gerenciamento de receitas.

O projeto permite visualizar receitas, pesquisar por nome, descrição ou ingredientes, acessar detalhes, cadastrar novas receitas e trabalhar com dados armazenados em uma API local utilizando JSON Server.

## 📌 Funcionalidades

- Visualização de receitas cadastradas
- Pesquisa de receitas por nome, descrição ou ingrediente
- Cadastro de novas receitas
- Visualização dos detalhes de uma receita
- Edição de receitas
- Organização das receitas por informações como tempo, dificuldade e tags
- Dashboard para visualização de informações
- Consumo de dados através de uma API local
